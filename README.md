# РХЛ U21 — Telegram-бот и мини-апп для болельщиков

Учебный проект: календарь, таблица, протоколы и лидеры Первенства России U21 (РХЛ) для всех 26 клубов, матч-центр
и игра дня «Раскат» — в Telegram: https://t.me/rhl_u21_bot

Здесь — открытая часть:

- `webapp/` — мини-апп Telegram, без сборки;
- `build_data.py`, `rhl_site.py`, `rhl_protocol.py`, `tg_channels.py` и соседи — сборка данных из открытых
  источников лиги и постов клубов;
- `raskat/`, `build_raskat.py` — игра дня «Раскат»;
- `guard.py` — сторож: проверяет сервер снаружи и пишет админам.

Бот, сервер и обработка видео — в закрытом репозитории. Данные о матчах — с сайта лиги rhl.fhr.ru.

Код открыт только для просмотра — см. `LICENSE`.
