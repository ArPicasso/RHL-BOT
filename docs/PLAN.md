# Работа над готовым проектом

С 06.10.2026. Приложение запущено и живёт сезон до 21.03.2027: мини-апп на Pages, бот и пять служб на VPS
(`bot`, `live`, `api`, `pages`, `clips`). Строить с нуля больше нечего. Дальше работа другого рода: держать систему
живой в каждый игровой день, чинить то, что ломается, и доводить начатое. План по этапам постройки —
`docs/ARCHITECTURE.md`, как система устроена сейчас — `docs/SYSTEM.md`.

## 1. Как работаем

| Шаг | Кто | Правило |
| --- | --- | --- |
| Просьба или поломка | владелец пишет в сессию Claude, или её находит сторож (раздел 4) | одна задача — одна ветка и один PR (правило 6) |
| Решение | Claude пишет ADR или дополнение, владелец отвечает | архитектура — до кода (правило 1); мелкая правка — сразу |
| Код и тесты | Claude | `python -m unittest discover -s tests` зелёный локально до пуша |
| Независимая проверка | агент-ревьюер (`/code-review`), только для PR, которые трогают службы (`bot.py`, `clips.py`, `server.py`, `live.py`) или данные о людях | Claude сливает сам (правило 8), поэтому второй взгляд — до слияния, а не после |
| Слияние и выкладка | Claude сливает, `deploy.yml` выкладывает | в ответе — что изменится у болельщиков и что проверить |
| Проверка после выкладки | Claude через `/api/agent/status` и `/api/live/*` в следующей сессии, владелец — в боте | что не сошлось — новый PR, а не правка руками на сервере |

Сессии Claude — в окружении **Default**: в нём `RHL_AGENT_TOKEN`, `RHL_API` и доступ к домену API. Сервер руками
меняет только владелец: всё остальное идёт через PR и выкладку.

## 4. Агенты, которые следят за системой

| Агент | Где живёт | Что делает | Кому пишет |
| --- | --- | --- | --- |
| Тревоги (ADR-022) | бот, раз в минуту | службы, пульс, VK, Telegram | админам |
| Проверка отметок (ADR-033) | служба `clips` | каждую отметку человека сверяет с табло и ходом часов; спор — отметившему | бот → отметившему |
| Сторож очереди Pages | задание Actions (шаг 1) | сборка мини-аппа ждёт дольше 30 минут — тревога | Telegram, напрямую с раннера |
| Внешний сторож живости | задание Actions (шаг 3) | `/api/health` молчит — сервер или Caddy легли | Telegram, напрямую с раннера |
| Утренний обход | ежедневная сессия Claude Code в 09:00 МСК (Routine), окружение Default | читает `/api/agent/status`, `/api/live/clips.json` и запуски Actions; что сломано — чинит PR'ом по этому плану, что требует решения — одной сводкой владельцу | владельцу в сессии |
| Проверяющий ИИ | задание Actions, после пилота (шаг 5) | читает табло на спорных голах | службе `clips`, вердиктом |

Утренний обход заводится одной командой, когда владелец скажет: Routine с этим планом в подсказке. Сторожа шагов 1 и
3 — код в репозитории, работают без Claude.
