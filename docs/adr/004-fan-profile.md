# ADR-004. Экран «Я» вместо «Команды»: паспорт болельщика, истории, приглашения

Статус: принято и сделано (уборка статусов 08.10.2026): вкладка «Я» с паспортом болельщика, «Позвать болеть вместе» и
карточки для Stories (`webapp/story.html`, `webapp/stories/`). Предложено 25.09.2026, прототип был в ветке
`claude/festive-feynman-rl3o0t`.

## Контекст

Четвёртая вкладка мини-аппа, «Команда», — это экран первого запуска, открытый второй раз:
шапка «Сейчас: …», переключатель оформления и сетка из 26 клубов. Разбор
(`docs/research/ui-audit-2026-09.md`) показал:

- **Вкладка обещает не то.** По слову «Команда» ждёшь свой клуб, а видишь 25 чужих
- **Четверть меню — под действие раз в сезон.** Команду почти никогда не меняют
- **Нет воронки в бота.** По ADR-003 бот напоминает, а мини-апп показывает. Но из мини-аппа в
  подписку не ведёт ни одна дорожка
- **Нечем поделиться.** Ссылка `startapp=<команда>` уже работает, но кнопки для неё нет. В
  детско-юношеской лиге болеют родители, друзья и одноклассники игроков — это главный
  бесплатный канал роста
- **Оформление не на своём месте.** Тему уже переключает кнопка в шапке любого экрана

В `docs/ARCHITECTURE.md` пятым экраном заложен «Я»: посещения, бейджи, прогнозы, напоминания.
Это решение — первый шаг к нему.

## Решение

**Вкладка «Я» — паспорт болельщика.**
- Сверху имя из Telegram (`initDataUnsafe.user.first_name`). Показываем и нигде не храним.
  Вне Telegram — «Профиль»
- **Паспорт болельщика** — карточка-стикер цвета `--violet`, как карточка скачивания у Slush.
  Внутри: эмблема, «Болею за», название клуба, сезон и три цифры сезона, те же, что на «Главной»
- Действия по порядку важности:
  1. **«В историю»** — `Telegram.WebApp.shareToStory` (Bot API 7.8+). Картинка — заранее
     нарисованная карточка клуба `webapp/stories/<id>.jpg`, 1080×1920. Подпись — ссылка на
     мини-апп с этим клубом. Имени и цифр на картинке нет: она общая для всех болельщиков
     клуба и не устаревает за сезон
  2. **«Позвать друга»** — окно выбора чата Telegram (`t.me/share/url`) со ссылкой на мини-апп,
     которая сразу открывает этот клуб
  3. **«Напоминания о матчах»** — открывает бота по ссылке `?start=remind`, бот сразу
     показывает включение напоминаний. Пока бот умеет только «Рязань-ВДВ»; для остальных
     клубов строка честно говорит «скоро»
- Внизу — «Сменить команду» и компактный выбор оформления

**Ссылка с командой не перезаписывает выбор.** `startapp=<id>` выбирает клуб только тому, у
кого команда ещё не выбрана. Уточнение к ADR-003: иначе приглашение от болельщика соперника
молча меняло бы человеку его клуб.
С 25.09.2026 (ADR-011) такая ссылка новичку клуб не выбирает, а открывает знакомство с его
талисманом: «Болеть за …» человек нажимает сам.

**Смена команды — лист, а не экран.** Сетка клубов открывается листом снизу, как карточка
матча, со строки «Сменить команду» и по нажатию на эмблему в шапке «Главной». Одно касание
по клубу — выбор, лист закрывается. Экран первого запуска не меняется.

**Картинки для историй** рисуются с той же вёрстки, что и мини-апп: `webapp/story.html?team=<id>`.
Скрипт `tools/render_stories.js` (Playwright, запускается руками) снимает все 26 и кладёт в
`webapp/stories/`. Перерисовывать нужно, когда меняются эмблемы, названия или сезон.

**Ссылки на бота и мини-апп** в данных: `build_data.py` пишет в `league.json` → `links`
`https://t.me/rhl_u21_bot` и `https://t.me/rhl_u21_bot/myapp`. Переменные окружения `BOT_LINK` и
`APP_LINK` (в GitHub Actions — Variables репозитория) их заменяют, например для тестового бота.
Без ссылки на мини-апп приглашение ведёт на адрес страницы с `?team=<id>`, без ссылки на бота
строки напоминаний нет.

## Альтернативы

- **Оставить «Команду» и добавить в неё статистику клуба.** Бомбардиров можно посчитать из
  протоколов, но по `docs/ARCHITECTURE.md` статистика игроков — этап 5 и требует согласия
  клуба. В U21 есть несовершеннолетние. Отложено до согласия
- **Рисовать картинку истории в браузере.** `shareToStory` принимает только адрес по HTTPS,
  а сервера у нас нет (ADR-003). Готовые картинки на GitHub Pages обходятся без сервера
- **Имя болельщика на картинке истории.** Тогда картинка персональная, и её надо где-то
  хранить. Отказались: хватает подписи, которую человек видит и правит перед публикацией

## Последствия

- Меняется `DESIGN.md`: вкладка «Я», компоненты «Паспорт болельщика», «Лист смены команды»,
  «Карточка для истории»
- В репозитории появляются 26 картинок, около 3 МБ. Они статичны и нужны раз в сезон
- Мини-апп зарегистрирован у @BotFather: `t.me/rhl_u21_bot/myapp`
- Бот учится ссылке `/start remind`. Формат `games.json` и время напоминаний не меняются
- Персональных данных не храним: имя только показываем. Выбор команды — как раньше, на
  устройстве и в CloudStorage
- Следующий шаг экрана «Я» по плану — напоминания о любой команде (подписки в боте), затем
  прогнозы и альбом наклеек сезона
