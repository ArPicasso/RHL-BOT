# ADR-026. Авторы голов по ходу матча из постов клубов

Статус: принято, 04.10.2026. Жалоба: «На сайте пишется, кто забил, а в нашем приложении просто гол команды».

## Контекст

Снимок источников 04.10.2026 в 14:13 МСК (идут Калуга — Динамо-576 и Ростов — Краснодар) показал:

- **Карточка матча на сайте лиги по ходу игры авторов не даёт.** Блока `matchcenter-hero__composition`
  нет совсем: только счёт и «2-й период». Он появляется после матча вместе с протоколом (ADR-019,
  дополнение 03.10). Поэтому служба `live` (`with_authors`) по ходу матча не находит, кого подставить.
- **«Кто забил» на сайте — это вкладка «Трансляция»**: фрейм `online.khl.ru/online/<id>.html`
  с тем же номером матча, что на сайте лиги. Онлайн КХЛ отвечает и серверу, и раннеру GitHub страницей
  403 «Обнаружена вредоносная активность, доступ ограничен». Защиту не обходим (ADR-012, раздел 6):
  ни подменой браузера, ни чужими адресами. Законный путь — письмо на `access_deny@khl.ru` с адресом
  сервера. Его пишет владелец, а не код.
- **Клубы ведут матч в каналах**: «Счёт в южном дерби открывает Григорий Сеснев! 🦅 0:1 🏝»,
  «Шайбу забросил Даниил Нуреев 🦅 0:2 🏝». Эти посты уже лежат в ленте матча (`events`, ADR-019, раздел 5),
  но как отдельные строки, а сам гол живого остаётся «Гол · Краснодар».

## Решение

1. **Разбор поста** — `matchday.goal_author`, без сети. В посте должны быть слово о голе, имя из двух
   слов с заглавной рядом с глаголом гола («забросил», «открывает счёт», «сравнивает» и т. п.)
   и ровно один счёт. Нет имени, счёта, или их несколько (там ещё «начало в 17:00») — поста как
   автора нет: лучше гол без автора, чем с чужим.
2. **Чей гол** — `build_data.apply_goal_authors` при сборке Pages:
   - имя есть в составе ровно одной из двух команд — это её гол, имя пишем как в протоколе.
     Состав — по протоколам сезона: строки состава, авторы, ассистенты и удалённые, потому что в
     протоколах нового сайта состав бывает из одних вратарей;
   - в составах имени нет — гол команды канала клуба. Пост канала лиги без состава не берём.
     Имя переставляем в «Фамилия Имя», если первое слово — имя из протоколов сезона;
   - счёт должен быть возможен для этой команды: у гостей «2:0» своим быть не может. Так ловим клуб,
     который пишет свой счёт первым.
   - скрытые по просьбе (ADR-007) — «Игрок скрыт».

   Итог — поле `goal: {team, score, name}` у события ленты в `league.json`.
3. **Мини-апп** ставит имя в гол живого без автора, если у поста та же команда и тот же счёт
   (`postAuthor`). Свой автор у гола живого (блок сайта после матча, онлайн КХЛ) главнее.

## Последствия

- Имя приходит со сборкой Pages, раз в 15 минут (`pages_kick.py`), а не сразу с голом. Гол
  появляется по счёту сайта, автор — позже.
- Только у клубов, которые ведут матч в канале. «Ростов» пишет «0:3 — Ещё одна шайба в наших
  воротах» без имени. У матча двух таких клубов автора по ходу не будет.
- Пуш бота о голе (ADR-024) уходит сразу, по счёту: автора в нём по-прежнему нет. Догонять пуш
  вторым сообщением не стали: два сообщения на гол — шум.
- Если КХЛ откроет доступ серверу, онлайн КХЛ станет первым источником авторов и минут, а посты —
  запасным.
