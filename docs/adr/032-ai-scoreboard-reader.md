# ADR-032. ИИ читает табло: проверка голов и разметка новых клубов

Статус: предложено, 06.10.2026; на 08.10 не начато — ждёт выбора владельца, где брать ИИ (`PLAN.md`, вопрос 3), пилот —
до покупки. Просьба владельца после двух ошибок сопоставления — «Калужские Ракеты — Динамо-576»
(повтор 1:0 открывался при 3:0 на табло) и «Факел Ямал — Ахмат-Гранит» (превью 1:3, а на табло 0:2): «Давай продумаем,
можем ли мы поставить какую-то ИИ, которая будет анализировать и помогать от таких ошибок».

## Контекст

Служба `clips` цифр на табло не читает. Она видит, что клетка счёта *сменилась*, и решает, какой это гол, по порядку
голов и времени сайта лиги (ADR-029, ADR-030). Отсюда два класса ошибок:

- **сбитый порядок**: табло пропустило смену (запись началась после гола, табло убрали) или приняло за смену фон
  (у «Факела» цифры без плашки) — дальше все голы команды съезжают на один;
- **разметка**: 19 клубов из 26 без разметки табло — их домашние матчи без секунд, превью и клипов, пока админ не
  перешлёт кадр в сессию Claude.

Что уже сделано без ИИ (ADR-031, дополнение 06.10, вечер): проверка цепочки картинок цифр («до гола — та же цифра,
что после прошлого гола, до первого — та же, что у соперника до его первого») и кнопки «табло сбилось» и «нет в
записи». Цепочка ловит сдвиг и шум, но не знает, *какая* это цифра: когда спорят две клетки, она отбрасывает голы, а не
чинит их.

## Варианты

| | Как | Плюсы | Минусы |
| --- | --- | --- | --- |
| **А. Своё распознавание цифр** | шаблоны цифр собираются из самой записи: секунды на часах идут 0–9 по кругу, десятки — 0–5 (ADR-030, «Что дальше») | бесплатно, на сервере, без внешних служб | у каждого клуба свой шрифт, у табло без плашки фон мешает; неделя работы и проверка на кадрах с сервера |
| **Б. Tesseract на сервере** | `apt install tesseract-ocr`, клетка счёта и часов, увеличенная в 4–8 раз | бесплатно, на сервере, за день | на мелких цифрах 480p и прозрачном табло ошибается; цвет и контраст настраивать под клуб |
| **В. Модель с картинками (Claude)** | 2–4 маленьких кадра на гол → JSON: счёт и часы на табло, видно ли табло | читает любое табло без настройки; может сам найти табло на целом кадре — разметка новых клубов без человека | платно; внешний API; **из России недоступен** (см. ниже) |

## Решение (предлагается): В поверх проверки цепочки, запросы — не с сервера

```
служба clips (VPS, Россия): спорный гол → 2–4 кадра рамки табло (JPEG, ~20 КБ) → бакет rhl-clips/frames/
   ↓
задание GitHub Actions (раннер вне России, раз в 15 минут — как сборка Pages): кадры → Claude → вердикт JSON
   ↓
вердикт → API сервера (/api/clips/verdict, подпись секретом задания) → служба clips: гол берёт, чинит или снимает
```

1. **Что спрашиваем.** По голу — кадр до смены счёта и кадр после, плюс кадр в секунду остановки часов: «какой счёт на
   табло, какое время на часах, видно ли табло вообще». Ответ — строго по схеме (structured outputs,
   `output_config.format`): `{"visible": bool, "home": int|null, "away": int|null, "clock": "mm:ss"|null}`.
   Совпал счёт до/после с голом протокола — гол подтверждён; нет — служба знает, какой гол на самом деле на этой смене,
   и переставляет секунды, а не выбрасывает их.
2. **Когда спрашиваем.** Только спорное: цепочка картинок разорвалась, самопроверка хода часов не сошлась, админ нажал
   «табло сбилось», клуб без разметки (кадр целиком: «где табло, где счёт и часы» → черновик разметки в `boards.json`,
   PR открывает задание, сливает владелец).
3. **Модель.** По умолчанию — Claude Opus 5.5 (`claude-opus-5-5`, $4 за миллион входных токенов, $20 — выходных, effort
   `low`). Картинка стоит примерно ширина × высота / 750 токенов: рамка табло 480×180 — около 115 токенов, кадр целиком
   1280×720 — около 1200. Гол — четыре рамки плюс инструкция и ответ: около 1000 входных и 200–400 выходных
   (рассуждение у Opus 5.5 не выключается) — порядка $0,01. Спорных голов в игровой день — 10–20, разметка нового
   клуба — раз: **меньше $10 в месяц**. Дешевле — Claude Sonnet 5.5 или Haiku 4.5, но это решение владельца: сначала
   стоит померить точность на кадрах 04–06.10, где мы знаем правильный ответ.
4. **Почему не с сервера.** API Anthropic в России недоступен, и обходить это туннелем мы не будем: запросы делает
   задание GitHub Actions — его раннеры вне России, — с ключом аккаунта владельца из поддерживаемой страны (ключ — в
   Actions Secrets, правило 2). Сервер только кладёт кадры и принимает вердикт.
5. **Персональные данные.** На кадрах — графика табло из публичной трансляции (рамка, без людей), кадр целиком —
   только для разметки нового клуба. О болельщиках в запросах ничего.

## Что решить владельцу

1. **Делать ли вариант В** (рекомендую) или начать с Б (Tesseract, бесплатно, слабее на прозрачных табло).
2. **Аккаунт и ключ API** — на кого заведён и из какой страны (нужна поддерживаемая), лимит расходов в консоли.
3. **Модель**: Opus 5.5 по умолчанию или дешевле после замера точности.
