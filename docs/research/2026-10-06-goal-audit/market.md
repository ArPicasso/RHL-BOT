# ИИ и видеоаналитика для секунды гола: что есть на рынке

Отчёт агента-разведчика, 06.10.2026. Задача: какие сервисы и бесплатные инструменты помогут найти секунду гола в записи
трансляции и проверить её; цены, точность и доступность — по первоисточникам.

Обозначения: **[П]** — первоисточник открыт и прочитан; **[П-в]** — цифры с официального домена, но из выдачи поиска
(сама страница из среды исследования не открылась: прокси закрыт для openai.com, ai.google.dev, aws, azure, доменов
Яндекса, Сбера, VK, twelvelabs, arxiv); **[В]** — вторичный источник; **[О]** — оценка агента.

Допущения расчётов: 600 голов и 113 матчей в месяц. Рамка табло 480×180 px — у Claude ⌈480/28⌉×⌈180/28⌉ = 126
токенов [П]. Гол: 4 рамки + ~400 токенов инструкции ≈ 900 входных, ответ ~120; у Sonnet 5.5 и Opus 5.5 ещё ~300 токенов
рассуждения. «Часы» — чтение часов по рамке раз в минуту в матчах 19 неразмеченных клубов: ~12 500 рамок в месяц, по
10 в запросе. Курс ≈ 83 ₽/$ [В].

## 2. Рекомендация агента

**Главное.** Секунду гола уже дают остановка часов, протокол и ход часов (ADR-031). ИИ нужен для одного — понять,
*какие* цифры на табло. Поэтому видеомодели и вендоры хайлайтов не нужны, наружу уходят только рамки табло.

**$0.** Вариант А ADR-032 — шаблоны цифр клуба из хода секунд 0–9 и 0–5. Первые подписи для шаблонов и **черновик рамки
для 19 неразмеченных клубов** — RapidOCR или PaddleOCR (PP-OCRv5 mobile): детектор текста на 5–10 целых кадрах ищет
`mm:ss`, у которого секунды меняются раз в секунду. Tesseract — только запасной. Звук — третья опора, только в окнах
превью: пики громкости, сирена, Whisper small int8. Бесплатный уровень Gemini основой не делать.

**До ~$20 в месяц (реально $1–12).** Всё из $0 плюс модель с картинками для спорных голов и разметки клубов. Есть
законный аккаунт Anthropic в поддерживаемой стране — Claude через раннер: Haiku 4.5 ≈ $1 на 600 голов, Sonnet 5.5 ≈ $4,
Opus 5.5 ≈ $7 (если пилот покажет, что младшие ошибаются); Batch −50 %. Нет такого аккаунта — Gemma 3 27B в Yandex AI
Studio прямо с сервера, ≈300–400 ₽ на 600 голов; модель выбирать пилотом, обе в одном прогоне. Вторая «читалка» для
голосования — Yandex Vision OCR, ~0,13 ₽ за рамку: модель и OCR не сошлись — превью админу.

**До ~$100.** Плюс две модели на **каждый** гол (Claude и Gemma), расхождение → превью: ≈$10–15. Чтение часов раз в
минуту во всех матчах неразмеченных клубов, пока нет шаблонов: Haiku ≈ $4, Sonnet ≈ $12, Gemma ≈ 1 400 ₽. Только с
письменного согласия лиги — Gemini Flash-Lite по окнам 3 мин (картинка + звук) как независимый детектор: ≈$3–4.
Twelve Labs, Rekognition Video и Video Intelligence не покупать: вся запись в 7–24 раза дороже бюджета, а часы табло они
не читают лучше рамок. Честно: дороже ~$20 деньги почти не покупают точность — предел в мелких цифрах 480p и
пропадающем табло.

**Поправки к ADR-032.**
1. Формула токенов теперь ⌈w/28⌉×⌈h/28⌉ [П]: рамка 480×180 → 126 токенов, кадр 1280×720 → 1196.
2. Рамки меньше 200 px увеличивать в 3–4 раза — это лишь десятки токенов.
3. Записать условие о поддерживаемых регионах и страну владельца ключа.
4. Не зашивать `claude-haiku-4-5`: модель выводится «не раньше 15.10.2026».

## 3. Пилот до покупки (3–4 матча, ≥20 голов)

**Набор.** «Ростов — Краснодар» 04.10 (4 гола с опорами админа); «Калужские Ракеты — Динамо-576» и «Факел Ямал —
Ахмат-Гранит» — две ошибки из ADR-032 (у «Факела» табло без плашки); один матч клуба без разметки; по возможности 480p и
720p. Плюс ≥200 подписанных вручную рамок со счётом и часами, из них ≥30 без табло (повтор, заставка). Набор
заморозить фикстурой в `tests/`.

**Участники** — на одних рамках и одном промпте со строгой JSON-схемой: Tesseract, RapidOCR, Gemma 3 27B, Claude
Haiku 4.5, Sonnet 5.5, Opus 5.5; по желанию Gemini Flash-Lite и Yandex Vision OCR.

| Метрика | Порог «годится» |
|---|---|
| Счёт на видимых рамках: точное совпадение | ≥ 99 % (неверный счёт — неверный гол) |
| Часы `mm:ss`: точное совпадение | ≥ 97 %; ошибки ±1 с — отдельно |
| Ложное чтение при пропавшем табло (`visible=false`) | ≤ 1 на 100 рамок |
| Секунда гола против опоры админа | ≥ 90 % в ±2 с, 100 % в ±5 с, **0 голов не той смены счёта** |
| Спорные голы | ≥ 80 % исправлены верно, 0 неверных перестановок |
| Разметка нового клуба: рамка часов против ручной | IoU ≥ 0,5, цифры читаются ≥ 95 % |
| Цена и время | токены из `usage` на 600 голов — в бюджете; CPU ≤ 20 мин на матч |

Разбивка по клубам: с плашкой и без, 480p и 720p. Модель, прошедшая только на клубах с плашкой, включается только для
них.
