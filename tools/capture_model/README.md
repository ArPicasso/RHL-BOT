# Модель «захвата карты»

Агентная модель игры «Наш лёд» (ADR-017): болельщики раз в тур расставляют одинаковые силы по
матчам, зоны городов переходят к клубам. Модель нужна не для продукта, а для решений: правило
прогоняем здесь и сверяем с бюджетом ниже. Цифры модельные — порядок величин, не прогноз.

Устроена так же, как `tools/fantasy_model` для «Звена», но меньше: ни пула игроков, ни цен, только
исходы матчей. Поэтому хватает stdlib, numpy не нужен.

## Что внутри

Один файл `sim.py`:

| Часть | Что делает |
| --- | --- |
| `load_rounds` | Матчи регулярки НМХЛ 25/26 из `history.json` по неделям Пн–Вс — 24 тура |
| `elo_probs` | Вероятность победы хозяев **до** матча: Elo обновляется по ходу сезона, без подглядывания |
| `ARCH` | 8 архетипов болельщиков: доли, шум восприятия силы команд, любовь к своему клубу, учёт толпы, частота захода. Доли — те же допущения, что в `fantasy_model` |
| `allocate` | Расстановка сил: жадно, по предельной выгоде следующей силы. Толпу знаток оценивает по **опубликованным** долям прошлого тура |
| `autopilot` | Публичное правило для тех, кто не пришёл: силы на матчи своего клуба и на фаворитов |
| `season` | Тур: расстановки → толпа → переход зон → очки → сходство расстановок |
| `metrics` | Метрики ниже |
| `VARIANTS` | Варианты правил: `base` — ядро ADR-017, остальные — проверки |

## Как запустить

```bash
cd tools/capture_model
python3 sim.py base 20      # ядро ADR-017, 20 прогонов — около минуты
python3 sim.py all 20       # все варианты рядом
```

## Метрики и бюджет

Правило проходит, только если не ломает ни одного порога.

| Метрика | Порог | Зачем |
| --- | --- | --- |
| Очки знатока к казуальному | +15…+40% | Ниже — тактика не решает, выше — казуальным нечего делать |
| Доминирующей стратегии нет: вариант `allexpert` | 95…105 | Если все играют лучшим образом, преимущества ни у кого нет |
| Сходство расстановок активных (Жаккар) | ≤ 0,40 | Выше — у игры один правильный ход, шаблон |
| Живая цель в своей ступени | ≥ 80% | Доля ходов, где место в группе 20 ещё достижимо |
| Казуальный хоть раз взял тур в своей группе | ≥ 50% | Азарт: выиграть неделю может любой |
| Захватов зон за тур | 1,5…4 | Карта меняется, но не мелькает |
| Зон у трёх самых больших фанбаз | ≤ 20% | Поправка на размер фанбазы работает |
| Новых источников и трат валюты | 0 | Валюты в игре нет вовсе (ADR-017) |
| Негативных публичных сигналов об игроке | 0 | Игроков в ядре нет: силы ставятся на матчи клубов |

## Чего модель не умеет

- Календарь 26/27 и состав РХЛ отличаются от НМХЛ 25/26: ушедшие клубы в выборке есть, новые — нет
- Доли архетипов и частота заходов — допущения, а не измерение
- «Поддержка» (тыкалка) не моделируется: она не даёт личных очков и на расстановку не влияет
- Клубные лиги, кубок и H2H второго круга — вне модели

Когда появятся результаты 26/27, модель стоит перекалибровать на них.
