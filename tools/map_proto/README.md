# Прототип «Карты»

Играбельный прототип второй механики «Нашего льда» (ADR-017, раздел «Пересмотр после прототипа»):
гексы по силуэту России, 26 клубов начинают с одной клетки — своего города, заряд копится сам,
красить можно только рядом со своими, отрезанное от города сереет, выездная победа открывает десант.

Нужен, чтобы проверять механику руками до того, как она попадёт в мини-апп. Первая версия
(расстановка сил по матчам) провалилась именно на этом: правила читались в тексте, но на экране
не было видно ни фронта, ни того, что твой ход меняет.

| Файл | Что делает |
| --- | --- |
| `board.py` | Поле: гексы внутри упрощённой границы России, город каждого клуба — ближайший гекс. Долгота за 70° сжата: 25 клубов живут западнее, «Ермак» — в Ангарске |
| `build.py` | Собирает `index.html`: поле, клубы с игровыми цветами, три настоящих матча на клуб из календаря |
| `page.html` | Страница игры с подстановкой `/*DATA*/` |

```bash
cd tools/map_proto && python3 build.py     # → index.html, открыть в браузере
```

Игровые цвета считает `build.py`: у половины лиги форма тёмно-синяя, на карте клубы сливались,
поэтому каждому подбирается похожий, но различимый цвет, и соседи по карте не совпадают.

Боты изображают болельщиков остальных клубов, матчи ускорены, тур идёт 45 секунд. Ничего из этого
в продукт не переносится: там тур — неделя, а исходы приходят из протоколов лиги.
